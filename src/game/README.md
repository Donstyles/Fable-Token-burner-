# `src/game/` – rules and data layer

Pure TypeScript, no Babylon, no DOM, no console. Randomness only through `Rng`
(`rng.ts`, mulberry32). Every module has a Vitest file next to it. MM6 rules are
followed where the community documents them; every simplification is listed
here and in the module's header comment. `fixtures.ts` is test data only.
